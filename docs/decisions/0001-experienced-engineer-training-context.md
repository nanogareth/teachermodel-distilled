# 0001 Target a technical training function for experienced engineers

## Context
Spec v0.1 (7 Oct 2026) was written for a different training organisation, with its own platform
integrations and partner data law. The train-the-trainer research of 23 Oct 2026 was framed for a
technical training function serving experienced engineers.

## Decision
v0.2 and this repository target a technical training function for experienced engineers: SME engineer
instructors (enablement, DevRel), professional, contract and partner instructors; experienced
engineer learners; GDPR and CCPA/CPRA. v0.1 is not part of this repository.

## Consequences
Integrations specific to the v0.1 organisation are out of this repo. Decision 0004 records who controls the data
of a deployment.
