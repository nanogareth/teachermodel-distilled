# Tour run sheet

Generated by `py scripts/tour.py --sheet` from the stops in `scripts/tour.py`; edit the stops, not this file.

## Before the demo

```powershell
py scripts/tour.py --check
```

This builds the tour store if it is missing (about 25 minutes for 26 simulated weeks, so run it the day before), runs every stop without opening anything, and checks each result. Then present from the browser:

```powershell
py scripts/tour.py --gui
```

It opens http://127.0.0.1:8765/ on this machine only. On the left are the stops, in the middle what to say and what each stop shows, and on the right the viewer: each command runs when you arrive at its stop, and the pages and the PDF open there too. Keys:

| Key | Does |
| --- | --- |
| Left and right arrows | previous and next stop |
| Up and down arrows | the stop's commands and pages |
| R | run the command again |
| N | hide or show what to say (when you share the whole window) |
| F | present: the viewer alone, for the audience |

The audience menu shows only the stops for one audience (`--audience leadership` starts with it set). After a click inside a page, click the bar above it before using the keys again. Without the browser, `py scripts/tour.py --audience leadership` walks the same stops in the terminal (Enter for the next stop, `b` to go back, `q` to quit) and opens each page in the default browser.

To type commands yourself during questions, point the CLI at the tour store first:

```powershell
$env:TEACHERMODEL_PRIVATE_DIR = "$HOME\teachermodel-tour"
```

## 5. Earning a clearance: blind observation

For: Instructors and clearers, Training team.

- A clearance needs observed sessions against the rubric's anchors, from more than one observer.
- Observers score blind: neither sees the other's scores until both have submitted.
- Every page works the same way. Read the summary, give your answer, press 'Save sign-off file'. That opens an email draft with the sign-off attached; send it from your own work mailbox. Nobody logs in anywhere.
- The daily job reads the sign-off mailbox, checks each sign-off against the page it came from, and writes the event.

Shows:

- opens `pages/observe--*.html` in the tour store

## 6. Two clearers decide, independently

For: Instructors and clearers, Leadership.

- Once the evidence is in (enough observations and a passed dry run for this unit and mode), two calibrated clearers decide on their own. Neither sees the other's decision.
- If they differ, the head of training resolves it. A clearance can come with conditions and a recheck date.
- The page pins the evidence by hash. If the evidence changes, the page reopens instead of approving something different.

Shows:

- opens `pages/clearer-decision-1--*.html` in the tour store

## 7. The record explains itself: a clearance's history

For: Leadership.

- Any clearance can be traced from the append-only event log alone: the round, the observations and observers, the dry run, the two clearers and the framework version.
- Nothing is edited or deleted. A correction is a new event, so the history an auditor reads is the history that happened.

Shows:

- `teachermodel history --clearance {partner_clearance}`
